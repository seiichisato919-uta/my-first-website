# SEO記事 禁止表現チェッカー

SEO記事の執筆時に使用してはいけない表現を自動検出・修正するWebアプリケーションです。

## 機能

### 1. 禁止表現の自動検出
以下の表現を自動的に検出します：

- 〜という
- 〜することができます。
- 大切です。
- 重要です。
- 鍵 / カギ
- 少なくありません。
- しばしば見られます。
- 一人ひとり / 一つひとつ / 1人1人 / 1つひとつ
- 第一歩
- 〜なのです。
- 秘訣
- なぜ / どのように / どうやって
- のです。
- ぜひ
- 多様 / 自身 / 土台
- 〜なのでしょうか。
- とても / 大幅な / 非常に

### 2. 漢字→ひらがな自動変換
以下の漢字を自動的にひらがなに変換します：

- 持つ → もつ
- 分かる → わかる
- 分かり → わかり
- 分かれば → わかれば
- 出来る → できる
- 言う → いう
- 通り → とおり
- 様々 → さまざま
- 〜の時 → 〜のとき

## 使い方

1. **ブラウザで開く**
   - `index.html` をブラウザで開いてください

2. **テキストを入力**
   - 上部のテキストエリアにSEO記事を貼り付けます

3. **チェック実行**
   - 「禁止表現をチェック」ボタン：問題箇所を検出して表示
   - 「自動修正」ボタン：漢字を変換し、禁止表現を【要修正: xxx】で強調表示

4. **結果を確認**
   - 禁止表現数と漢字変換数が表示されます
   - 各問題箇所の詳細リストが表示されます
   - 修正後のテキストが下部に表示されます

5. **コピー**
   - 「コピー」ボタンで修正後のテキストをクリップボードにコピーできます

## ファイル構成

```
seo-article-checker/
├── index.html    # メインHTML
├── style.css     # スタイルシート
├── script.js     # JavaScript（チェック・修正機能）
└── README.md     # このファイル
```

## 技術スタック

- HTML5
- CSS3 (グラデーション、レスポンシブデザイン)
- Vanilla JavaScript (フレームワーク不要)

## 注意事項

- 禁止表現は完全一致でチェックされます
- 自動修正後も、【要修正: xxx】部分は手動で適切な表現に書き換えてください
- ブラウザのJavaScriptが有効になっている必要があります

## カスタマイズ

禁止表現や変換ルールを追加・変更する場合は、`script.js` の以下の部分を編集してください：

```javascript
    // ここに禁止表現を追加
];

    // ここに変換ルールを追加
};
```
